# NTE_Database
A curated collection of POSCAR crystal structures and corresponding QHA calculation outputs for two-dimensional materials investigated for negative thermal expansion (NTE). These files support structural analysis, thermal-property evaluation and further computational studies.
The associated machine-learning models, analysis notebooks and datasets, including `Classification-7-Copy3.ipynb`, `NN-TEC-Copy17.ipynb`, `NN-alpha_max-Copy19.ipynb`, `data_8.csv` and `external_test.csv`, are available in my co-author Arko Mohari's GitHub repository: https://github.com/arko-mohari/NTE.

Please cite our published work when reusing the data or codes: https://doi.org/10.1002/asia.70604
